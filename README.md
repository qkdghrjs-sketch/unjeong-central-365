**아임웹 [코드(HTML) 위젯]에 그대로 붙여 넣는 것을 전제로** 만들었습니다.

- 미리보기: https://yium-redesign.vercel.app
- 실제 운영 사이트: https://yium.kr (연결 예정) / https://yium-board.vercel.app

## 붙여넣는 방법

`blocks/` 폴더의 파일을 **순서대로 하나씩** 아임웹 코드 위젯에 붙여 넣으세요.
한 파일이 한 섹션이고, 파일 안에 HTML·CSS·JS가 모두 들어 있습니다.

## 아임웹에서 안 깨지게 한 장치

아임웹은 자체 CSS를 `!important` 로 밀어넣기 때문에 일반 웹 코드를 그대로 넣으면 무너집니다.
그래서 아래를 모든 블록에 적용했습니다.

- 모든 스타일을 `#eumHero`, `#eumDoc` 같은 **고유 아이디 안으로 가둠** — 다른 위젯과 절대 섞이지 않습니다
- 클래스 이름을 전부 `eum_` 으로 시작 — `.wrap` `.btn` `.title` 같은 흔한 이름과 충돌 없음
- `ul·li·p·span·a` 의 여백/불릿/밑줄을 블록 안에서 초기화
- `float / clear / width / position / overflow / box-sizing` 을 강제 지정해 아임웹 레이아웃 간섭 차단
- 스크립트는 블록마다 독립 실행, `data-eum-ready` 로 **두 번 실행 방지**
- 폰트(SUIT)는 블록마다 `@import` — 어느 블록만 넣어도 글꼴이 유지됩니다

## 수정할 때

- **색상**: 각 파일 맨 위 `#eumXxx { --eum-teal: ... }` 값만 바꾸면 그 섹션 전체가 바뀝니다
  - 딥 메디컬 틸 `#0C2D37` / 프레시 민트 `#36B8A5`
- **여백**: 같은 자리의 `padding:150px 0 162px` 숫자를 조절
- **공지사항 글**: `07-notice.html` 의 `<a class="eum_item">` 4개에서 제목·날짜·링크만 교체
- **링크**: 현재 전부 `https://yium.kr/...` 입니다. 도메인이 다르면 일괄 치환하세요
