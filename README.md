# 이움내과 수정버전 — 메인페이지 디자인 시안

이움내과의원(경기 고양시 덕양구 화정동) **메인페이지 리디자인 시안**입니다.
기존 메인의 섹션 구조와 내용은 그대로 두고, 디자인만 새로 짰습니다.

- 배포 주소: https://yium-redesign.vercel.app
- 현재 운영 사이트: https://yium-board.vercel.app (연결 예정 도메인 yium.kr)

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 메인페이지 전체 (HTML · CSS · JS 한 파일에 모두 들어있음) |

CSS와 스크립트가 파일 안에 함께 들어 있어서, 이 파일 하나만 있으면 그대로 열립니다.

## 섹션 구성 (기존 구조 유지)

| 번호 | 섹션 | 내용 |
| --- | --- | --- |
| 01 | 헤더 | 메뉴 · 대표번호 · 예약 버튼 (모바일은 햄버거 메뉴) |
| 02 | 히어로 | 3장 자동 슬라이드 + 하단 탭 + 진료 요약 퀵바 |
| 03 | 의료진 | 조현경 원장 — 약력 · 자격 |
| 04 | 진료클리닉 | 만성질환클리닉 4 + 인공신장센터 3 |
| 05 | 진료철학 | 이움내과의 5가지 약속 (사진 + 아코디언) |
| 06 | Y.I.U.M 케어 여정 | 6단계 통합 케어 |
| 07 | 진료환경 | 사진 9장 가로 슬라이드 |
| 08 | 오시는 길 | 진료시간표 · 지도 · 인증 사실 |
| 09 | 푸터 | 병원 정보 · 모바일 하단 고정 버튼 |

## 디자인 기준

- 메인 컬러: 딥 메디컬 틸 `#0C2D37` / 프레시 민트 `#36B8A5`
- 서체: SUIT (본문) · Noto Serif KR (원장 문구)
- 모바일 화면 기준으로 먼저 확인했습니다.

## 수정할 때

- 색을 바꾸려면 `index.html` 위쪽 `:root { ... }` 안의 값만 고치면 사이트 전체에 반영됩니다.
- 실제 사이트에 붙이실 때는 링크의 `https://yium-board.vercel.app` 를 `https://yium.kr` 로 일괄 치환하시면 됩니다.
- 각 섹션은 `<!-- ═══ [번호] 섹션명 ═══ -->` 주석으로 구분되어 있어, 섹션 단위로 잘라 쓰실 수 있습니다.

## 안내

의료광고법을 고려해 최상급·비교 표현과 치료효과를 단정하는 문구는 쓰지 않았습니다.
원장 성함 · 약력 · 진료시간은 병원에서 확인된 내용만 사용했습니다.
